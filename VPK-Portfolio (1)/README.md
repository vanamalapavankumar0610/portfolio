# VPK Portfolio

A clean, professional, light-only developer portfolio for VANAMALA PAVAN KUMAR.

## Files
- `index.html` — portfolio structure/content
- `styles.css` — responsive styling and animations
- `script.js` — navigation, reveal animations, certificate lightbox, mailto contact form
- `assets/` — the three uploaded certificate images

## Run locally
Open `index.html` directly in Chrome, or use the VS Code Live Server extension.

## Deploy
This is a static website and can be deployed to GitHub Pages, Vercel, Netlify, or similar static hosting.

## Notes
- GitHub links are included only where the user provided them.
- No live-demo URLs were invented for projects without supplied links.
- The contact form uses `mailto:` and opens the visitor's default email app.
- The design is an original implementation inspired by the requested Dribbble reference, not a direct copy.

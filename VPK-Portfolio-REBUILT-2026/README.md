# VANAMALA PAVAN KUMAR — Portfolio

Static responsive portfolio website.

## Run locally
Open `index.html` directly in Chrome, or use VS Code Live Server.

## Included
- Responsive light-only portfolio
- Sticky navigation and mobile menu
- Animated hero developer visual
- About, Skills, Projects, Certificates, Achievements and Contact sections
- Certificate preview/download lightbox
- Mailto contact form
- GitHub and LinkedIn links
- No backend required

## Main files
- index.html
- styles.css
- script.js
- assets/
